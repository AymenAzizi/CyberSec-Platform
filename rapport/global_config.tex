\frenchAbstract{Ce projet de fin d'\'etudes porte sur la conception et le d\'eveloppement d'une plateforme web semi-agentique de reconnaissance de surface d'attaque, int\'egrant une mod\'elisation par graphe de connaissances (PostgreSQL 16 / Apache AGE), une IA locale contrainte (Ollama / \texttt{qwen2.5-coder}) pour la production de \textit{Remediation-as-Code}, et une cha\^ine DevSecOps automatis\'ee (SAST, SCA, SBOM CycloneDX, Trivy, Cosign). %%% EN
\englishAbstract{This graduation project focuses on the design and implementation of a semi-agentic web platform for attack surface reconnaissance, integrating a knowledge graph (PostgreSQL 16 / Apache AGE), a constrained local AI (Ollama / \texttt{qwen2.5-coder}) for Remediation-as-Code generation, and an automated DevSecOps pipeline (SAST, SCA, CycloneDX SBOM, Trivy, Cosign). Developed at Designet Web Agency with a Laravel 11 back-end and five Python Flask microservices orchestrated via Redis Streams, the platform validated 140 automated tests and sustained a benchmark load of 50 concurrent users under a mandatory Proof of Authorization (PoA) governance.}
